### 🍽️ [Diário Alimentar](https://github.com/gustavo2807v4/diario-alimentar)

PWA de registro alimentar e treino com IA, com camada de progressão em RPG.

O problema: apps que deixam a IA calcular a refeição inteira dão números diferentes
para a mesma comida. A solução aqui é uma restrição — **o modelo nunca faz uma conta.**
Ele identifica o alimento, estima os gramas e aponta a linha da tabela TACO. Toda a
aritmética acontece no dispositivo, então o resultado é determinístico e auditável.

JavaScript puro, zero dependências em runtime, zero servidor. IndexedDB local, abre
offline, instalável no celular.

`JavaScript` · `PWA` · `IndexedDB` · `Gemini API` · `Vanilla JS`

🔗 [Ver no ar](https://diario-alimentar-equipe-gust.vercel.app)
